# Laboratorio de Infraestructura On-Premises

## Objetivo
Documentar de forma práctica la implantación de servicios de infraestructura,
seguridad y comunicaciones en un entorno on-premises virtualizado, como parte
del Máster en Sistemas.

## Entorno
Laboratorio on-premises basado en máquinas virtuales VMware, simulando una
infraestructura corporativa con servidores y conectividad entre sedes.

## Tecnologías
- Virtualización con VMware
- Firewall
- VPN: OpenVPN (site-to-site y point-to-site)
- Servidores Windows / Linux
- Servidor de licencias
- Empaquetado y despliegue de software (MSI)
